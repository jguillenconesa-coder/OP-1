# Original factory samples

These 28 mono WAV files are original procedural sounds generated by
`scripts/generate-factory-samples.py`, with deterministic random seeds.
No Teenage Engineering firmware, recordings or third-party sample packs are used.

Full legal text: `licenses/CC0-1.0.txt` in the project root.

Three kits (Studio, Circuit, Dust), each containing kick, snare, closed/open hat,
tom, clap, crash and rim. Four melodic samples have a C4 / MIDI 60 root.
All files are PCM16, 32 kHz, peak normalized with short edge fades.
