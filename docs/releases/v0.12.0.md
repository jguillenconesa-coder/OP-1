# Pocket One 0.12.0

**Value 246 FX** conecta el LFO reconstruido con los cuatro colores de Punch.
En set 4, los mandos MIDI siguen Speed / Amount / Destination / Target Colour;
FREE PHASE conserva la fase entre notas. Los rangos de las opciones antiguas y
sus identidades host se mantienen. Proyectos/slots antiguos cargan Value apagado.
[Guía y método](../value246-native.md).

Las **4.096 llamadas** del oráculo coinciden en estado completo, display, buffer
de parámetros y retorno; se contrastan rangos, fase y cálculo de tempo. REA
inventaría por separado los siete tipos LFO del DB. El port cubre la ruta FX;
los destinos synth/drum/ENV, otros LFO y la temporización de la máquina completa
siguen pendientes. El reloj 44.100/64 del adaptador es una hipótesis explícita.

**BROWSE → 246 Value FX Studies** añade Helicopter (manual study), didg + Value
Blue y roar bass + Value Blue. Helicopter combina Digital/ADSR/Punch/Value con
el teclado de pantalla a +4. La calibración display/raw y la comparación con
audio real siguen pendientes. Los sonidos anteriores se conservan.

Las pruebas cubren siete tasas, migración 0.11, guardado/slots/clipboard,
mandos MIDI, pánico y audio independiente de bloques 64/128/256. Se amplía el
benchmark a 84 cargas con ocho voces y automatización de Value/Punch/motores.
La comparación con 0.11.0 conserva **1.794.048 muestras idénticas** en las rutas
anteriores con Value apagado. [Evidencia](v0.12.0-validation.json).

No se certifica fidelidad acústica completa ni cero dropouts. La validación de
este paquete en Windows nativo, Ableton y ASIO sigue pendiente.
