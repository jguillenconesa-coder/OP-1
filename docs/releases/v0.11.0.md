# Pocket One 0.11.0

Se añade **Punch 246**, reconstrucción independiente del efecto mono de rev246.
Sus 131.072 muestras, 2.048 estados completos y valores de display coinciden con
las instrucciones originales aisladas bajo el modelo GNU documentado. La tabla
de 129 coeficientes y los rangos se obtienen mediante funciones originales.
[Guía y reproducción](../punch246-native.md).

**BROWSE → 246 CORE + Punch** incorpora tres variantes de Digital/Phase con los
campos FX almacenados. Los 32 CORE anteriores mantienen Punch apagado. Los cuatro
mandos MIDI siguen Frequency / Punch / Rounds / Power en set 3; los cinco nuevos
parámetros se añaden al final y se guardan en sesiones, slots y LIFT/DROP.

El feedback puede mantener una cola; el VST3 declara cola potencialmente infinita
con Punch activo y STOP/CC120 la corta. La conversión causal de tasa, DC a 5 Hz,
limitación de salida e inserción suavizada son propias. 44,1 kHz FX es una
hipótesis de integración, no una medición del codec. No se espera un bloque extra
de entrada, pero filtros/interpolación tienen retardo de grupo.

El teclado alcanza **−4…+4 octavas**, con límite MIDI 127. Se guarda su posición
en proyecto, slots y clipboard. Esto no transpone MIDI externo ni aplica todavía
todos los campos octave originales de los patches.

Se documenta el objetivo completo por motor, filtro, FX, envolvente, LFO y modo de
ejecución. REA confirma un inventario synth sin truncar; el catálogo numérico
incluye **169 patches y 24 kits**. Los ejercicios **Helicopter / Singing Birds**
del manual quedan desglosados por dependencias. No se presentan registros aún
pendientes como presets originales implementados. [Matriz](../original-op1-coverage.md).

Las pruebas incluyen estados DSP, streaming, siete tasas de host, MIDI, slots,
migración 0.10, octavas, audio independiente de bloques 64/128/256 y pánico.
El benchmark tiene 72 cargas. La comparación con 0.10.0 produce **1.720.320
muestras idénticas** en las trayectorias anteriores con Punch apagado.
[Evidencia](v0.11.0-validation.json). No se certifica cero dropouts ni fidelidad
acústica de toda la máquina; la validación Windows real/ASIO sigue pendiente.
