# Pocket One 0.9.0

Los 16 presets Phase 246 CORE incorporan una reconstrucción opcional del núcleo
ADSR usando sus primeros cuatro campos almacenados. El set 2 y los cuatro knobs
MIDI siguen esa envolvente. Los proyectos y slots de 0.8.0 mantienen el modo
anterior al no contener el nuevo flag. Los parámetros nuevos se añaden al final;
ningún ID/índice anterior cambia. [Guía y capturas reales](../phase246-native.md).

String ahora usa retardo fraccional, compensa el filtro de promedio y sigue bend
sobre la cuerda principal. El timbre/afinación cambian ligeramente. Es un modelo
propio, no un port del motor original. FILTER LFO ya actúa sobre Phase nativo y
muestras CLEAN mediante una inserción suavizada. STOP/CC120 limpian voces y colas
sin borrar buffers grandes en el callback; cambiar de preset conserva las colas
master. El host recibe la duración de las nuevas envolventes y delays en cascada.

El ADSR reconstruido coincide con **2.621.440 muestras y 20.480 estados** del
firmware aislado bajo el modelo GNU documentado con writeback D-reg diferido.
Cinco probes independientes muestran el problema del modelo stock. Los resultados
anteriores Pd/FM/Q15 no cambian; la copia LUT deja de desplazarse en ese modelo.
Se conservan ambos resultados y el parche GNU separado. [Método](../envelope246-research.md).

Once suites Linux y trece Windows bajo Wine, más instalación/desinstalación y
carga del VST3 instalado. [Validación](../validation.md). No hay nueva latencia
declarada; los tiempos de VM/Wine no certifican cero dropouts ni miden ASIO.
El arranque gráfico del standalone y Live 10.2.4/Windows real siguen pendientes
de validar; la limitación de la ventana Wine también se observó en 0.8.0.

NCO, salida, mezcla/velocidad, flujo de dither, FX/LFO y otros motores siguen
siendo total o parcialmente propios. No se afirma fidelidad completa al aparato
ni a sus presets. [Estado y pendientes](../audio-engines.md).
